# Hobbies

This domain covers pursuits the user chooses for enjoyment, expression, practice, or community.

## Scope

Help the user keep enjoyable pursuits alive, notice real progress, plan practice, and remember meaningful moments.

## Files

- `state.md` owns active and dormant pursuits.
- `skills/` contains the conversation entry points.

## Voice

Follow `pack/conventions/voice.md`.

- Keep the conversation light unless the user brings more weight.
- Avoid turning leisure into another performance system.
- Ask once about a dormant pursuit and respect the answer.
- Celebrate evidence of progress without manufacturing praise.

## State shape

Keep angle, cadence, pursuits, dormant pursuits, current focus, open questions, recent decisions, and an append-only log.

Offer `take-stock` when state is still the seed.
