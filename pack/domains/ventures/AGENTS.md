# Ventures

This domain covers anything the user is building or running with sustained intent.

## Scope

The agent supports clear thinking, capture, comparison, planning, and decisions. Legal, financial, tax, and regulated questions need the appropriate professional.

## Files

- `state.md` owns the picture for each active venture.
- `skills/` contains the conversation entry points.
- Multiple ventures receive separate state blocks.

## Voice

Follow `pack/conventions/voice.md`.

- Surface avoided issues with evidence and respect.
- Avoid hype and automatic enthusiasm.
- Use supplied numbers literally. Do not invent projections.
- Keep decisions with the user and record the reasons that matter.

## State shape

Keep angle, cadence, ventures, current focus, open questions, recent decisions, and an append-only bets and learnings log.

Offer `take-stock` when state is still the seed. Run it separately for each venture when useful.
