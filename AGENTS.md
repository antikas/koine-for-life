# Koine for Life - project context

## Context authority

This file owns runtime-neutral project context. Provider-specific files import it and contain mechanics only.

Read `GETTING-STARTED.md`, `PRIVACY.md`, and the relevant pack instructions before changing behaviour or personal files.

## Project boundary

Koine for Life is a public personal operating system pack. People use natural language to reflect, remember, review, and make decisions across seven life domains.

Personal state belongs in the user's local pack instance. This repository provides the reusable pack, examples, skills, reviewers, and conventions.

## Privacy and agency

- Never place passwords, full account numbers, identity numbers, credentials, or another person's sensitive data in the pack.
- Read and write only the files needed for the current conversation.
- Explain material file changes in plain language.
- Obtain explicit approval before sending, publishing, purchasing, booking, deleting, or changing an external system.
- Treat financial, health, legal, and safeguarding matters within the limits declared by each domain.

## Repository structure

`pack/AGENTS.md` owns pack routing. Each domain `AGENTS.md` owns its local scope, state shape, safety limits, and voice.

Keep examples fictional. Keep reusable pack instructions free of a specific user's personal facts.
